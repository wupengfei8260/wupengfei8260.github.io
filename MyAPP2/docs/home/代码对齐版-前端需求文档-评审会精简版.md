# 代码对齐版-前端需求文档（评审会精简版）

适用范围：index.html + modules/home/index.js。

## 背景与目标
- 首页是壳应用的默认落地页，负责展示工作台信息并分发到子页面。
- 当前版本重点是跑通首页主链路，不以实时后端数据为目标。

## 页面结构与流程
- 入口：index.html 默认加载 home 模块。
- 首页结构：顶部信息区 + 统计卡片 + 工具分页 + 复盘日报 + 弹层区。
- 内部分发：localNavigateTo 支持 reviewDaily、reviewDailyYd、signedReport，其他模块透传外层。
- 关键跳转：
  - 待签收 -> mustSign(initialTab=dispatch)
  - 汇总数据 -> signedReport(view=summary)
  - 复盘指标 -> reviewDaily(initialLargeMetricId, initialSubMetricId)

## 交互与状态（含边界与异常）
- 状态：activeReviewDay 控制今日/昨日指标；mustSignCount 由本地 tabMeta 聚合。
- 交互：消息显隐、二维码弹层开关、复盘日维度切换、指标点击跳转、键盘可达。
- 异常：子模块加载失败仅 console.error；昨日预览失败显示降级文案。

## 数据结构与字段清单
- 复盘指标项：{ label, count, mainId, subId }
- 子模块映射：{ file, hideNav }
- 核心路由参数：
  - reviewDaily: day, initialLargeMetricId, initialSubMetricId, switchTarget, backTarget
  - signedReport: view, selectedDateKey, courierId

## 验收标准
- 首页首屏可完整渲染。
- 今日/昨日切换后复盘网格正确刷新。
- 三条关键跳转（mustSign/signedReport/reviewDaily）可稳定触发并带参数。
- 二维码和消息面板可正常开关。
