## 分期管理模块（新增）

### P0. 分期策略说明

- 本文档为全量指标主档，不因一期范围收缩而删除其他指标定义。
- 一期仅更新“分期状态、实现差异、待确认项”，不删除二期指标正文。
- 二期及后续迭代直接复用本主档，在原指标下更新状态与实现内容。

### P4. 智能体更新规则

- 允许更新：分期范围总览、分期状态、分期变更记录、自动维护区块。
- 禁止更新：非本期指标的正文定义与字段说明。
- 若本期不包含某指标，仅更新其状态为“待排期/暂缓”，不得删除该指标章节。

## 四、列表共性交互规范

| 规范项       | 说明                                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------------- |
| 每页展示数量 | 默认一次加载**100条**，超过100条时分页加载                                                               |
| 去处理后移除 | 有【去处理】按钮的数据，**处理完成后自动从当前列表中移除该条数据**，无需手动刷新                         |
| 单号点击     | 弹出全屏物流详情覆盖层，展示：运单号、当前状态、寄收件人信息（姓名/电话/地址）、时间轴轨迹；关闭按钮收起覆盖层 |
| 空态显示     | 列表无数据时显示"暂无明细数据"，附虚线边框容器，不显示空白页                                                   |
| 滑动滚动     | 内容区独立滚动（`#metricContent`），顶部指标看板区域固定不随内容滚动                                         |
