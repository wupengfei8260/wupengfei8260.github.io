# 代码对齐版需求文档（基于当前前端实现）

## 背景与目标
- 项目为单页前端壳应用，主容器在 index.html，通过底部导航动态加载模块。
- 目标是提供首页工作台、咨询服务、项目数据维护、个人设置、扫码识别、复盘日报（汇总与明细）等功能。
- 当前实现以前端静态数据与模拟逻辑为主，少量浏览器能力调用（摄像头、拨号、localStorage）。

## 页面结构与流程
- 应用入口
  - index.html 初始化模块映射：home、consult、data、profile、reviewDaily、reviewDailyYd。
  - 默认启动 loadModule('home')。
  - loadModule(moduleId, routeParams) 负责：动态 import 模块、注入容器、透传 navigateTo/showToast/routeParams。
- 底部导航流程
  - 首页/资讯/客户/我的：点击后切换模块并更新 active 样式。
  - 中间扫描按钮：不切页，调用 openScanner() 弹出扫描遮罩。
- 首页（modules/home/index.js）
  - 渲染头部（改进建议、消息、二维码）、统计区、工具区、复盘日报入口卡片。
  - 交互：
    - 改进建议按钮：toast 提示。
    - 消息按钮：消息面板显示/隐藏。
    - 二维码按钮：模态框打开/关闭（支持点遮罩关闭）。
    - 工具区横向滚动：更新分页圆点。
    - 复盘日报卡片：navigateTo('reviewDaily')。
- 咨询页（modules/consult.js）
  - 渲染咨询方式、流程、FAQ、温馨提示。
  - 数据源为本地常量 consultData。
- 数据页（modules/data.js）
  - 渲染项目表格，支持新增项目。
  - 表单校验：name 非空，progress 在 0-100。
- 我的页（modules/profile.js）
  - 渲染深色模式开关与清除数据按钮。
  - 读取/写入 localStorage.darkMode。
  - 清除数据触发 localStorage.clear() 后 reload。
- 扫码弹层（modules/scan.js）
  - openScanModal(options) 创建覆盖层，尝试调用 getUserMedia 获取后置摄像头。
  - 若浏览器支持 BarcodeDetector，则每 500ms 识别一次，识别成功 toast 后关闭。
  - 不支持 BarcodeDetector 时，仅展示提示文案。
- 复盘日报明细（modules/home/reviewDaily.js）
  - 通过 routeParams 控制“今日/昨日”状态、返回目标、初始大类指标/子指标。
  - 主结构：顶部标题+日期切换+指标tab+明细内容区+物流详情全屏层。
  - 点击日期切换：navigateTo(switchTarget, switchTargetParams)。
  - 点击返回：恢复容器样式并 navigateTo(backTarget, backTargetParams)。
  - 指标逻辑：
    - 大类：揽派异常、服务质量、今日必签、未出库、潜在风险、时效看板、派签时长、预估收入、等级、行动建议、核心概览。
    - 子类：如超时揽收/未取件/未电联/未上门签收、虚假签收/破损/遗失。
    - 明细中支持：运单号点击查看物流详情、姓名电话脱敏开关、去处理按钮、必签列表打电话。
  - 数据来源：本地 mock 常量，若明细不足会自动补齐至 count。
- 复盘日报汇总（modules/home/reviewDailyYd.js）
  - 顶部汇总页展示收入、风险、时效、核心概览、等级、行动建议。
  - 风险区数字支持跳转昨日明细：navigateTo('reviewDaily', { day:'yesterday', initialLargeMetricId, initialSubMetricId, ... })。
  - 返回按钮：navigateTo('home')。
  - “昨日”切换按钮：navigateTo('reviewDaily')。

## 交互与状态（含边界与异常）
- 全局状态
  - currentModule：当前模块名。
- 首页状态
  - msgList 显示/隐藏。
  - qrModal 显示/隐藏。
  - toolScroll 滚动位置 -> dot active 状态。
- 数据页状态
  - items 数组为当前项目列表。
  - addForm 显示/隐藏。
- 我的页状态
  - isDark 从 localStorage 读取。
  - 切换时直接改 document.body 颜色。
- 扫码状态
  - activeOverlay 防止重复弹层。
  - stream/detector/timer 生命周期由 closeModal 统一回收。
- 复盘日报状态
  - currentLargeMetricId/currentSubMetricId 控制面板。
  - plainTextMap 控制姓名电话脱敏显示。
  - 昨日模式下部分指标计数由 yesterdayCountMap 覆盖。
- 异常处理
  - 模块加载失败：显示“加载失败”卡片与错误 message。
  - 扫码加载/摄像头失败：status 显示错误文案。
  - 电话按钮号码缺失：showToast('号码无效')。
  - 数据页校验失败：toast 提示范围 0-100。

## 数据结构与字段清单
- 模块映射（入口）
  - key: string（home/consult/data/profile/reviewDaily/reviewDailyYd）
  - value: { name: string, file: string }
- 路由参数（reviewDaily）
  - day: 'yesterday' | undefined
  - hideMustSign: boolean
  - switchLabel: string
  - switchTarget: string
  - switchTargetParams: object
  - backTarget: string
  - backTargetParams: object
  - initialLargeMetricId: string
  - initialSubMetricId: string | null
- 明细数据样例字段
  - addressPhone: { address, name, phone, trackingNo }
  - fakeDetail: { trackingNo, signTime, complaintType, signType, signContent }
  - lostBrokenDetail: { trackingNo, dispatchTime, lostSource|brokenSource, respLink, penalty }
  - callDoorDetail: { trackingNo, dispatchTime, signTime, signPerson, typeTag }
  - mustSign: { trackingNo, name, phone, address }
- 咨询数据字段
  - quickEntries: [{ title, desc, tag }]
  - faqList: [{ question, answer }]
  - process: string[]
- 数据页字段
  - item: { name, progress, status }

## 验收标准
- 启动后默认展示首页，底部导航可切换到咨询/数据/我的。
- 点击中间扫描按钮可弹出扫描层，并可点击关闭。
- 首页“复盘日报”卡片可进入复盘明细页。
- 复盘明细页可切换指标、查看运单详情、执行“去处理”提示、返回上一页。
- 复盘汇总页风险数字可跳转到昨日明细页对应指标。
- 数据页新增项目在输入合法时可写入表格，非法输入有提示。
- 我的页深色模式开关可持久化到 localStorage，并在再次进入时恢复。
