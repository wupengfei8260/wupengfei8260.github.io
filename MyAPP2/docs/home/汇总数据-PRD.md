# 汇总数据-PRD

## 1. 目标

- 功能目标：提供一个按日期范围汇总的业务数据页面，支持在【派签量】与【揽件量】两个维度间切换查看。
- 适用页面/模块：`modules/home/signedReport/index.js`，从首页汇总入口进入。
- 不包含范围：不包含真实后端接口联调、不包含单号明细跳转到外部业务页。

## 2. 流程

- 触发入口：用户在首页点击【汇总数据】入口进入页面。
- 前置条件：页面默认展示【派签量】，默认日期范围为【近七天】。
- 主流程（按步骤编号）：
1. 页面顶部展示标题【汇总数据】，右侧展示【子账号汇总】。
2. 首行展示两个 tab：【派签量】【揽件量】，默认选中【派签量】。
3. 第二行展示 4 个日期端筛选按钮：【近七天】【上周】【本月】【上月】。
4. 第三行展示开始日期和结束日期的预览卡片，点击预览卡片会联动到第四行的日期选择控件。
5. 第四行展示开始日期-结束日期两个日期选择控件，用户修改任一日期后，表格按新的区间重新汇总。
6. 下方表格按天展示【时间】【分发量】【签收量】【异常签收】【操作】；表格首行展示总计。
7. 点击任一行的【查看】按钮，展示当前日期或总计范围的单号明细。
- 异常/兜底流程：
  - 当开始日期晚于结束日期时，页面自动交换两者，保证区间合法。
  - 当手动改日期后不再匹配 4 个预设按钮时，预设态显示为自定义范围。

## 3. 接口

- 获取接口：当前前端使用本地 mock 数据；后续可接入 `GET /api/v1/home/summary-data`。
- 提交接口：无。
- 入参字段：
  - `tabId`: `dispatch` | `pickup`
  - `rangeId`: `lastSeven` | `lastWeek` | `thisMonth` | `lastMonth` | `custom`
  - `startDate`: `YYYY-MM-DD`
  - `endDate`: `YYYY-MM-DD`
- 出参字段：
  - `rows[]`: 按天返回的汇总行，包含 `dateKey`、`dispatchCount`、`signCount`、`abnormalCount`、`bills[]`
  - `totals`: 当前区间的总分发量、总签收量、总异常签收量
  - `detail`: 点击【查看】后展示的单号明细列表
- 失败处理策略：
  - 若接口不可用，保留当前页面筛选状态并提示加载失败。

## 4. 验收

1. 页面默认进入【派签量】tab，且默认日期范围为【近七天】。
2. 点击 4 个预设日期按钮后，开始日期和结束日期会同步变化，表格内容随之更新。
3. 表格首行展示总计，且总计值等于当前区间内各天数值之和。
4. 点击【查看】可以看到对应日期或总计范围的单号明细。
5. 页面标题右侧固定展示【子账号汇总】。
6. 回归影响范围：首页入口、汇总数据页、日期筛选与单号明细展示。
