## 3.【需求背景】

### 3.1.目的

本需求用于规范首页【复盘日报】的展示与查看流程：功能用户从首页点击【复盘日报】后，默认进入今日明细；用户可切换查看昨日汇总，并在昨日汇总中点击指标跳转到昨日明细对应位置。

本文只描述【首页入口 - 今日明细 - 昨日汇总 - 昨日明细跳转】相关功能，不扩展其它无关能力。

## 4.【功能详细说明】

### 4.1.产品流程图

1. 用户在首页点击【复盘日报】入口。
2. 系统进入复盘日报页面，默认展示【今日明细】。
3. 今日明细页默认展示一级指标列表，点击一级指标后可查看对应二级指标或对应明细内容。
4. 用户可点击页面顶部切换按钮查看【昨日汇总】。
5. 昨日汇总页展示昨日各汇总指标，用户点击汇总中的某一指标后，跳转到昨日明细页，并定位到对应的一级指标及二级指标。
6. 昨日明细页支持继续切换一级指标、二级指标查看具体内容。
7. 今日明细页和昨日明细页的数据源获取均可留空，支持后续手动补充。
8. 今日与昨日页面顶部均保留日期切换按钮，点击可在【今日】与【昨日】之间切换。

### 4.2.页面结构说明

复盘日报页面按以下模块组织展示：

1. 页面顶部区域
   - 返回按钮。
   - 页面标题【复盘日报】。
   - 今日/昨日切换按钮。
2. 日期状态区域
   - 今日明细默认展示今日状态。
   - 切换后进入昨日汇总或昨日明细状态。
3. 指标内容区域
   - 一级指标标签区。
   - 二级指标标签区。
   - 明细展示区。
4. 汇总展示区域
   - 昨日汇总卡片区。
   - 汇总指标点击跳转区。

### 4.3.首页入口与默认进入规则

- 页面范围：首页。
- 触发入口：首页卡片【复盘日报】。
- 点击入口后进入复盘日报页面。
- 默认进入状态为【今日明细】。
- 默认进入后，页面应直接展示今日对应的明细内容，不额外要求用户再次选择日期。
- 页面顶部日期切换按钮默认显示当前状态文案，今日页显示【今日】，昨日页显示【昨日】。

### 4.4.今日明细页展示规则

- 今日明细页为默认页。
- 页面顶部应展示当前查看状态，便于用户识别正在查看今日数据。
- 今日明细页中，一级指标以主标签形式展示。
- 若一级指标下还有二级指标，则展示二级指标标签。
- 点击一级指标后，页面内容切换到该一级指标对应内容，同时刷新该一级指标下的二级指标区域。
- 点击二级指标后，页面内容切换到该二级指标对应明细内容。
- 当一级指标无二级指标时，点击该一级指标后直接展示该指标对应的明细卡片或说明内容。

### 4.5.昨日汇总页切换规则

- 页面支持从今日明细切换到昨日汇总。
- 切换后，页面展示昨日各指标的汇总信息。
- 昨日汇总页主体包含【业务量与预估收入】、【潜在风险追踪】、【时效与效率看板】、【今日核心概览】、【当前等级与权益】、【明日行动建议】等模块。
- 昨日汇总页内的指标点击区域主要包括：
  - 待处理异常中的【超时揽收】【未取件】【未电联】【未上门签收】。
  - 服务质量中的【虚假签收】【破损】【遗失】。
  - 时效与效率看板中的【1030签收率】【派签时长】。
  - 结算风险中的【6天未出库】。
- 昨日汇总页中的汇总指标支持点击跳转。
- 点击汇总指标后，不只打开昨日汇总本身，而是直接跳转到昨日明细页对应的一级指标/二级指标位置。
- 跳转后，页面应自动定位到被点击的指标内容，减少用户再次查找成本。
- 当点击的是二级指标时，昨日明细页需同时定位一级指标标签和该二级指标内容。
- 当点击的是一级指标汇总项时，昨日明细页需定位到该一级指标下的默认首个二级指标或对应内容区。

### 4.6.昨日明细页展示与返回规则

- 昨日明细页与今日明细页共用同一套指标结构。
- 昨日明细页进入后默认展示从汇总页点击进入的目标指标。
- 昨日明细页支持继续切换一级指标、二级指标查看具体内容。
- 昨日明细页顶部可通过切换按钮返回今日明细。
- 昨日明细页的展示内容与今日明细页保持同一套章节结构，区别仅在日期状态和数据来源口径。

### 4.7.页面内切换与展示/消失效果

本需求不涉及弹框交互，不新增弹框能力。页面之间主要为顶部切换按钮与内容区切换，不产生额外弹层。

### 4.8.数据源与手动补录规则

- 本需求中的各指标数据源字段允许留空。
- 数据源可由研发或运营后续手动补充。
- PRD 不强制约束接口字段命名，不强制约束数据来源是接口、静态配置还是人工录入。
- 只要求页面具备展示、切换和跳转能力。
- 每个一级指标、二级指标对应的数据源获取方式均可在后续实现中单独补充，不影响本 PRD 的交互定义。

### 4.9.一级指标功能描述

今日明细和昨日明细中的一级指标如下，二者展示口径保持一致，差异仅在默认日期状态与部分汇总数值：

1. 揽派异常
   - 一级指标用途：承载揽收、派件相关的异常数据总览。
   - 展示形式：一级指标标签 + 对应异常内容区。
   - 点击行为：选中后展示该模块内容，并同步展示其二级指标。
   - 适用范围：今日明细、昨日明细。
2. 服务质量
   - 一级指标用途：承载虚假签收、破损、遗失等服务质量问题。
   - 展示形式：一级指标标签 + 对应质量内容区。
   - 点击行为：切换到服务质量模块后，展示对应二级指标。
   - 适用范围：今日明细、昨日明细。
3. 今日必签
   - 一级指标用途：展示今日必须优先处理的签收数据。
   - 展示形式：单独内容卡片或列表。
   - 点击行为：进入该指标明细后展示对应必签数据。
   - 适用范围：今日明细、昨日明细。
4. 未出库
   - 一级指标用途：展示超期未出库相关数据。
   - 展示形式：单独卡片，强调数量与风险提示。
   - 点击行为：进入该指标的明细或说明内容。
   - 适用范围：今日明细、昨日明细。
5. 潜在风险
   - 一级指标用途：展示可能影响派签、签收、投诉的风险项。
   - 展示形式：风险卡片组合。
   - 点击行为：查看风险项明细。
   - 适用范围：今日明细、昨日明细。
6. 时效看板
   - 一级指标用途：展示签收率等时效指标。
   - 展示形式：看板卡片。
   - 点击行为：查看对应时效数据说明。
   - 适用范围：今日明细、昨日明细。
7. 派签时长
   - 一级指标用途：展示派签时长及效率表现。
   - 展示形式：看板卡片。
   - 点击行为：查看派签时长相关说明。
   - 适用范围：今日明细、昨日明细。
8. 预估收入
   - 一级指标用途：展示业务量与预估收入。
   - 展示形式：收入组合卡片。
   - 点击行为：查看收入构成与对比说明。
   - 适用范围：今日明细、昨日明细。
9. 当前等级
   - 一级指标用途：展示业务员当前等级与权益。
   - 展示形式：等级卡片。
   - 点击行为：查看等级详情或权益说明。
   - 适用范围：今日明细、昨日明细。
10. 明日行动建议
    - 一级指标用途：展示下一步优化建议。
    - 展示形式：建议列表。
    - 点击行为：查看建议内容，不做额外交互。
    - 适用范围：今日明细、昨日明细。
11. 今日核心概览
    - 一级指标用途：展示当日整体表现总结。
    - 展示形式：概览卡片或列表。
    - 点击行为：查看概览说明。
    - 适用范围：今日明细、昨日明细。

补充说明：

- 业务量与预估收入、潜在风险追踪、时效与效率看板、当前等级与权益、明日行动建议、今日核心概览均可作为一级内容模块独立展示。
- 当页面进入【昨日明细】后，一级指标仍按上述口径展示，支持通过顶部切换按钮重新返回【今日明细】。

2. 未取件

4. 未上门签收
   - 功能描述：展示未上门签收相关异常数据。

   - 功能描述：展示虚假签收相关数据。

### 4.11.昨日汇总到昨日明细的跳转规则

- 昨日汇总页中的指标可点击。
- 点击后，系统携带被点击的一级指标标识，进入昨日明细页。
- 若汇总指标属于带二级指标的模块，则同时携带二级指标标识。
- 跳转完成后，默认展开被点击的一级指标，并自动定位到对应的二级指标。
- 若汇总指标没有二级指标，则只定位到一级指标对应内容。

### 4.12.展示与关闭效果

- 今日明细页、昨日汇总页、昨日明细页均为页面内切换，不要求新增弹窗。
- 从首页进入后，页面默认展示今日明细。
- 从今日明细切换到昨日汇总时，页面保留当前页面结构，仅替换内容区域。
- 从昨日汇总点击指标跳转昨日明细后，页面应直接展示目标内容，不要求额外二次确认。

### 4.14.验收口径

研发实现后，需满足以下验收点：

1. 首页点击【复盘日报】后，默认进入今日明细。
2. 今日明细页可正常切换到昨日汇总，且顶部切换按钮文案与当前日期状态一致。
3. 昨日汇总页中可点击的指标，点击后能跳转到昨日明细对应一级指标和二级指标位置。
4. 今日明细页中的一级指标、二级指标均可独立展示对应内容。
5. 各指标数据源可留空占位，不影响页面结构和跳转逻辑。
6. 异常场景下页面不崩溃，能按约定展示空态或提示。

### 4.13.异常情况处理

- 数据源为空：允许展示空态或占位态，页面不应报错。
- 指标跳转失败：保持当前页面不变，并提示跳转失败。
- 未找到对应二级指标：仅定位一级指标内容，不阻断页面展示。
- 手动补录数据未完成：可保留空值，不影响页面结构和交互。
