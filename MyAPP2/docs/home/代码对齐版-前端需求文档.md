# 代码对齐版-前端需求文档

适用范围：仅基于 index.html 与 modules/home/index.js 当前实现。

## 背景与目标

- 项目为单页壳应用，首页模块由入口页面动态加载并渲染到统一容器。
- 首页承担业务看板角色，提供统计卡片、工具区、复盘日报入口与基础消息交互。
- 当前版本目标是跑通首页主流程与子页面分发，数据以本地常量与本地组合数据为主。

## 页面结构与流程

- 入口加载流程
  - index.html 在模块映射中声明 home 指向 modules/home/index.js。
  - 启动时默认调用 loadModule('home')，再由模块 render 注入页面结构。
- 首页内部路由流程
  - modules/home/index.js 内定义 subModules：reviewDaily、reviewDailyYd、signedReport。
  - localNavigateTo 规则：命中 subModules 则动态 import 子模块；未命中则透传到外层 navigateTo。
- 首页布局结构
  - 顶部区：改进建议按钮、滚动通知、二维码按钮、消息按钮。
  - 中部区：统计卡片、工具区分页滚动、快捷功能条、复盘日报模块、活动横幅。
  - 弹层区：二维码弹层、昨日复盘预览弹层。
- 首页核心跳转
  - 待签收卡片：跳转 mustSign，并传入 initialTab=dispatch。
  - 汇总数据卡片：跳转 signedReport，并传入 view、selectedDateKey、courierId。
  - 复盘日报指标：根据当前日维度跳转 reviewDaily，并传入 initialLargeMetricId、initialSubMetricId。
  - 昨日复盘预览：点击预览壳体后进入 reviewDailyYd。

## 交互与状态（含边界与异常）

- 状态变量
  - activeReviewDay：控制复盘日报模块展示今日或昨日指标。
  - mustSignCount：由 createMustSignTabData 返回的 tabMeta 中 zcw 与 dispatch 计数累加得到。
- 主要交互
  - 改进建议按钮点击后调用 showToast。
  - 消息按钮控制消息面板显隐。
  - 二维码按钮打开弹层，支持关闭按钮与点击遮罩关闭。
  - 工具区横向滚动时，更新分页圆点激活状态。
  - 复盘日报日期切换触发网格重渲染，点击指标触发跳转。
  - 待签收与汇总数据卡片同时支持点击与键盘 Enter/空格触发。
- 边界与异常
  - 子模块动态加载失败时仅 console.error，不向页面展示失败态。
  - 未提供 localNavigateTo 场景下，相关跳转降级为 showToast。
  - 昨日复盘预览加载失败时，预览容器显示失败文案。

## 数据结构与字段清单

- 入口注入参数
  - render(containerId, { showToast, navigateTo })。
- 子模块映射
  - subModules[item] = { file, hideNav }。
- 复盘指标项结构
  - { label, count, mainId, subId }。
  - 今日示例：揽收超时、未取件、虚假签收、遗失、破损、今日必签、未电联、未上门。
  - 昨日示例：同类指标，且存在 6日未出库（subId 为空）。
- 跳转参数结构
  - reviewDaily：{ day?, switchLabel?, switchTarget?, hideMustSign?, backTarget?, initialLargeMetricId, initialSubMetricId }。
  - signedReport：{ view, selectedDateKey, courierId }。
  - mustSign：{ initialTab }。

## 验收标准

- 页面启动后默认进入首页，且能完整渲染顶部区、统计区、工具区、复盘日报区。
- 点击待签收卡片可触发 mustSign 跳转参数传递。
- 点击汇总数据卡片可触发 signedReport 跳转参数传递。
- 复盘日报今日/昨日切换后，网格指标与计数发生对应切换。
- 点击任一复盘指标可触发 reviewDaily 跳转，并带上对应 mainId/subId。
- 二维码弹层可正常打开和关闭；消息面板可正常展开和收起。
